# Molecular Chemistry Lab

An interactive, browser-only chemistry learning platform built with HTML5, CSS3, SVG and vanilla JavaScript.

## Run
Open `index.html` directly in a modern browser.

## Features
- Animated molecule explorer
- VSEPR geometry visualizer
- Chemical bonding animations
- Bond polarity/electronegativity lab
- Hybridization orbital visualization
- Molecular polarity and dipole visualization
- Molecule comparison
- Compact interactive periodic table
- Conceptual reaction/energy visualizer
- Five chemistry calculators
- Learning mode
- Chemistry quiz with score and accuracy
- Global search
- localStorage learning progress
- Responsive layout
- Reduced-motion support
